# Config safety (wave 1): progress

Branch `claude/config-safety-bab75b`. Scope: `docs/ROADMAP.md` wave 1 `config-safety`; starting plan from `docs/progress/config-tools.md` "Next". Stopped at the usage guard (5-hour window at 84%, started at 81% because other sessions had used it) after the rules layer.

## Done

- **Rules for values that are dangerous together** (`core:config` `ConfigRules.kt`, tested in `ConfigRulesTest`). `ConfigWarning` moved here from `ConfigWriteCheck.kt` and became data: each entry lists the settings it involves (`params`, for marking rows) and its condition; `Config.writeWarnings(limits: HardwareLimits? = null)` evaluates them all, skipping a rule whose settings the definition lacks (app configs raise nothing). `List<ConfigWarning>.byParam()` maps settings to their warnings. `Config.batteryVoltage()` is the empty..full range from `si_battery_cells` and the per-cell range in `si_battery_type`'s enum name (`BATTERY_TYPE_LIION_3_0__4_2`, `..._LIIRON_2_6__3_6`; lead acid has none). Temperatures are read as ints or doubles (they are ints in 7.01). Rules, each with its source in KDoc:
  - VESC Tool 6.05's three: `ABS_CURRENT_CLOSE`, `SLOW_ABS_CURRENT`, `OVERMODULATION` (unchanged behaviour).
  - Battery: `BATTERY_CUTOFF_ORDER` (start ≤ end), `BATTERY_CUTOFF_BELOW_EMPTY` (end below cells × empty), `BATTERY_CUTOFF_ABOVE_FULL` (start above cells × full), `BATTERY_ABOVE_MAX_VIN` (full battery above `l_max_vin`), `BATTERY_CUTOFF_BELOW_MIN_VIN` (end below `l_min_vin`: undervoltage fault cuts before the ramp).
  - `FET_TEMP_ORDER`, `MOTOR_TEMP_ORDER` (start ≥ end), `DUTY_ORDER` (max ≤ `l_min_duty`).
  - `ERPM_UNREACHABLE`: FOC only, `l_max_erpm` above full voltage × max duty × overmod / √3 / flux linkage (as ERPM).
  - Hardware (`HardwareLimits`, all fields optional, unchecked when null): `CURRENT_ABOVE_HARDWARE`, `VOLTAGE_ABOVE_HARDWARE`, `ERPM_ABOVE_HARDWARE`, `DUTY_ABOVE_HARDWARE`.
  - The firmware defaults (3 cells, cutoff 10/8 V) raise `BATTERY_CUTOFF_BELOW_EMPTY`; `ConfigWriteCheckTest` now filters to VESC Tool's three.
- `./gradlew test :app:testDebugUnitTest :app:assembleDebug` green at this commit.
