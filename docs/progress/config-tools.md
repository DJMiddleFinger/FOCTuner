## Done (commit `ccbfcf3`)

`./gradlew :core:config:test :core:vesc:test :core:sim:test :app:assembleDebug` green.

- **XML** (`core:config` `ConfigXml.kt`, `QtNumber.kt`): `ConfigXml.write(config, root)` / `read(stream, root, base)`, VESC Tool's format byte for byte: `<?xml version="1.0" encoding="UTF-8"?>`, 4-space indent, `ConfigVersion` 4 (`VT_CONFIG_VERSION`), every parameter in definition order including the non-transmitted ones (motor brand, model, description, quality...), doubles as `QString::number` ('g', 6 digits, `1e-05`), ints as C `int` (uint32 above 2^31 written negative, read back unsigned), Qt's escaping (`&quot;` too, control characters dropped), empty strings as `<x></x>`, trailing newline. Reading follows `setXML`: first element named `root`, values not clamped, unparseable numbers read as 0, unknown elements listed, missing parameters keep the base value. DOCTYPE refused. Roots: `ConfigKind.xmlRoot` = `MCConfiguration` / `APPConfiguration`.
- **Write check** (`ConfigWriteCheck.kt`): `Config.notAppliedIn(readBack)` = `checkDifference` (ints/strings exact, doubles float-relative 1e-4, 1e-2 for double16; FOC offsets ignored unless `foc_offsets_cal_mode` bit 1). `Config.writeWarnings()` = the three 6.05 checks (abs current within 1.3x of motor/brake current, slow abs current, overmodulation >= 1.16).
- **Storage** (`ConfigBackupStore.kt`): `ConfigBackupStore(dir)`: `<uuid>/<created>/mcconf.xml|appconf.xml|backup.properties` (name, automatic, created, firmware, hardware); list newest first, save, load onto a base, delete, deleteAll, `pruneAutomatic(uuid, keep)`. The XML files load in VESC Tool. `ConfigCache(dir)`: last config per UUID and kind (VESC Tool 7.01 `conf_cache`), atomic replace.
- **Client** (`core:vesc`):
  - `VescController.writeConfig` now sends the packet twice back to back like VESC Tool 7.01 and returns after the first ack once the duplicate ack arrived (or the timeout passed), so it can't answer a later request (`requestTwice` in `ConfigWrite.kt`, via `session.incoming`; config writes serialised by a mutex). `VescSession` is unchanged.
  - `writeConfigChecked(kind, config)` -> `ConfigWriteResult(applied, notApplied)`; `applyAppConfig(config)` = COMM_SET_APPCONF_NO_STORE (fw >= 6.00); `bundledSeriesFor(version)`, `readMatchingConfig(kind, version, base)` (series by version, then by signature).
  - `ConfigBackups.kt`: `VescClient.configTargets()` (attached + CAN VESCs, BMS/modules skipped), `controller(target)`, `backUpConfigs(store, firmware, name, automatic, base)`, `restoreConfigs(store, backup, firmware)` (read live, apply backup XML, checked write, one retry on timeout).
  - `ConfigProfiles.kt`: `ConfigProfile` (VESC Tool `MCCONF_TEMP` + name, defaults from `createMcconfTemp`), `isInUse`, `fromConfig` ("Read current configuration"), `Config.erpmPerMeterPerSecond()`, `Config.withProfile()`, `applyProfile(profile, store)` = COMM_SET_MCCONF_TEMP_SETUP with store / forward_can=1 / ack=1 / divide=0 as VESC Tool sends it; `toProperties()` / `profilesFrom()` for storage.
  - `MultiSettings.kt`: `MultiSettingGroup` (General / Limits with separators / FOC / BMS, VESC Tool's lists), `writeMotorParams(firmware, values)` (read, set, checked write; reports params the firmware lacks).
- **Simulator** (`ConfigWriteSim.kt` + dispatch lines): COMM_SET_MCCONF keeps stored offsets unless writable and applies the 60_MK6 limits (currents ±120 A, abs 160 A, VIN 6-57 V, ERPM ±200k, duty, FET temp, scales, `l_erpm_start`, overmod 1-1.5, `foc_sl_erpm_start`); COMM_SET_MCCONF_TEMP(_SETUP) with speed->ERPM conversion, divide, optional input currents, forward to the other motor, ack; COMM_SET_APPCONF_NO_STORE.
- Tests: `ConfigXmlTest` (Qt number cases, exact layout, round trips, setXML rules, uint32, DOCTYPE), `ConfigWriteCheckTest` (check, offsets, warnings, backup store, cache), `ConfigToolsTest` (double send counted, clamped params reported, NO_STORE, profile on both motors, backup + restore across CAN, multi settings, definition fallback, profile storage).
